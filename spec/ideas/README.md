# Ideas — your blank space

Everything in this folder is **thinking out loud**. The loop may read it for
context and will never build from it. Write badly here. Contradict yourself.
Leave things half-finished for a month.

That guarantee is the point: if half-formed ideas sat in the area notes, they'd
be read as requirements, and the loop would go build one.

## The three tiers

| Where | What it means | What the loop does |
|---|---|---|
| `spec/ideas/` | Thinking. Nothing is decided. | Reads for context. **Never builds from it.** |
| `spec/00-` … `90-` | The spec — how CardOps is MEANT to work. | Builds to match. Where a note and the code disagree, **the note wins**. |
| `spec/INBOX.md` | Orders. | Does it next. |

## How an idea graduates

You decide when, and it's a deliberate act — nothing promotes itself:

- **Still thinking?** Leave it here.
- **Decided how it should work?** Move the substance into the relevant area
  note. It's now the spec, and the loop will build toward it.
- **Want it built now?** One line in `INBOX.md` → *Do next*. It can be rough;
  if it's too vague you'll get a question back rather than a guess.
- **Turned out to be a bad idea?** Delete it, or don't. Nothing here rots.

## Making notes

New note anywhere: **Ctrl+N**. Name it whatever. Link with `[[double
brackets]]` — a link to a note that doesn't exist yet is fine, it just marks
something worth writing later. Obsidian will create it when you click it.

There's no structure to conform to. If a shape emerges after a few weeks, that
shape is worth more than one imposed now.
